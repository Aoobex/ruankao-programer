# 软考初级《程序员》5 天冲刺系统

**在线直接用：<https://aoobex.github.io/ruankao-programer/>**

一个**纯离线**的学习/备考系统。不用装环境、不用联网、不用服务器，双击 `index.html` 就能用。

> 面向零基础：每张知识卡都是能直接背的结论，每道题都带解析。

---

## 一、先搞清楚规则（这决定你怎么花这 5 天）

| 项目 | 基础知识（上午卷） | 应用技术（下午卷） |
|---|---|---|
| 题型 | 75 道单选题 | 5 道大题（填空/写结果为主） |
| 满分 / 及格 | 75 / **45** | 75 / **45** |
| 时长 | 两科连考共 240 分钟，本科目 90~120 分钟 | 本科目 120 分钟 |
| 内容 | 计算机系统、操作系统、数据结构与算法、程序语言、软件工程、面向对象、数据库、网络、多媒体、标准化与知识产权、办公软件、专业英语 | 试题1 流程图；试题2~4 C 语言；试题5 C++ / 试题6 Java（二选一） |

**关键点：**
- 及格线是每科 45 分（满分 75 的 60%），**两科都要过**，单科成绩不保留。
- 你说的"60 分"我按**每科 60 分**当目标，比及格线高 15 分，是这个系统的默认训练强度。
- 机考，题目可切换，**先扫一遍再动手**，不会的标记后回头做。

## 二、怎么用（三句话）

1. 先看 **「5天计划」** 页，按 D1→D5 做，每天勾掉。
2. 每天先看 **「知识卡」** 页（当天模块），再点 **「刷题」** 把当天模块刷 15~40 题。
3. 第 5 天做 **2 次「模考」**（75 题 / 120 分钟），然后把 **「错题本」** 清零。

| 页面 | 作用 |

## 进度放在哪、怎么跨设备

学习进度**同时存在两个地方**：

1. **浏览器本地**（localStorage 的 `rk5.v1`）——你刷题时实时写，关掉页面还在
2. **仓库里的 `data/progress.json`**——页面启动时读它，作为跨设备的进度来源

### 一键上传

双击项目里的 **`sync-progress.bat`**。

它做的事：

1. 在 `下载` 目录找最新的 `progress*.json`
2. 校验是不是本系统导出的
3. 覆盖 `data/progress.json`
4. `git commit` + `git push`
5. 内容没变就跳过，不产生空提交

指定文件或只提交不推送：

```powershell
.\sync-progress.ps1 -File "D:\some\progress.json"
.\sync-progress.ps1 -NoPush
```

### 手动两条命令

```powershell
# 先在网页点「导出进度」，用下载的 progress.json 覆盖项目里的同名文件，然后：
cd E:\MyProject\ruankao-programer
git add data/progress.json
git commit -m "更新学习进度"
git push
```

`data/progress.json` 是普通被 git 跟踪的文件，不在 `.gitignore` 里，直接提交就行。

新机器打开页面（或直接看 GitHub Pages），会自动载入这份进度。

### 规则

- 本机**没有**进度 → 直接用 `progress.json`
- 本机有进度，但 `progress.json` 的 `savedAt` **更新** → 采用仓库版（你在另一台机器上学得更多）
- 本机有进度且不比仓库旧 → **保留本机**，不会被旧文件冲掉
- `file://` 打开时浏览器禁止 `fetch` 读本地文件，此时只用 localStorage；导出照常可用

**为什么要导出而不是自动写文件**：静态网页没有写本地文件的权限，浏览器也不允许它读项目目录。
所以"写回 progress.json"这一步必须由你点导出 + commit，这是纯静态方案能做到的最短路径。

题库规模：**412 道选择题**，答案分布 A/B/C/D 各 25%（防止"全选 B"蒙分），每题都有解析。
知识卡：**199 张**，按考纲分值排序；其中 **193 张配了 225 道例题**（题目 → 分步过程 → 答案），
专治"规则看得懂、题目不会做"。剩下 6 张是「下午题例题精讲」本身，已经是例题。

> 例题举例（原码反码补码那张卡）：
> 已知 8 位补码 `11111011`，求真值 → 全部取反得 `0000 0100` → 加 1 得 `5` → 最高位是 1 所以添负号 → **-5**。
> 每一步都写清在算什么，并补一句"为什么能这样算"。

## 五、目录结构

```
ruankao-5day/
  index.html          入口，双击即可
  app.css  app.js     界面与逻辑（纯原生 JS，无依赖）
  run-server.ps1      可选：想用手机/局域网访问时启动本地服务器
  data/m01..m11.js    知识卡 + 题库（每行都是数据，改起来很直观）
  data/ex-*.js        知识卡例题（按 模块id#卡片序号 挂到卡片上，不动卡片原文）
  data/progress.json  学习进度（被 git 跟踪，直接 commit 即同步）
  sync-progress.bat   一键上传：双击它
  sync-progress.ps1   上面那个批处理的实现
  tools/build-data.js 数据校验 + 打散答案位置（改完数据跑一次）
```

> 官方《程序员教程》PDF 是受版权保护的教材，**不在本仓库中**（已在 `.gitignore` 排除），需要的请到
> [ruankaodaren/ruankao](https://github.com/ruankaodaren/ruankao) 自行下载，仅作个人备考参考。

改题库：编辑 `data/*.js` 里的题目对象（`q` 题干、`o` 四个选项、`a` 正确答案下标 0-3、`e` 解析、`tag` 考点、`lv` 难度），
然后跑 `node tools/build-data.js`——它会校验格式并保证答案分布均匀。

## 七、已知取舍（自己心里有数）

- **知识产权-外观设计专利**：按 2021 年 6 月起施行的现行《专利法》写 **15 年**（旧教材写 10 年）。考试以现行法为准。
- **数据结构-数组地址题**：题干都明确写出下标范围（如 `A[1..8][1..10]`）和存储方式，避免不同教材记法歧义。
- **软件质量特性**：按 ISO 9126 的六项写（可扩展性不在其中）。
- 题目是**按考点重写**的练习，不是历年真题原文；难度略低于真题原卷，用来建立信心和查漏。
